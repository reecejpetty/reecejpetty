# Hi, I'm Reece

I am an aspiring web developer, currently self taught. I have been interested in making websites since I was a kid, using site builders like Freewebs, and later creating basic websites with limited HTML & CSS. Now I mostly work on apps that are used to help out at my work, learning as I go. We make a product called a bumpbar, a special keyboard used by cooks in restaurant kitchens to bump and manage food orders. My first major project was an internal order management website (made with Flask), used to create and manage the progress of our bumpbar orders. It is based on kitchen display systems (KDS) and can be used with our bumpbars. I have also created an app for users to design and generate custom configuration files for our bumpbar.

## Skills
